# Архитектура

Статус: рекомендуемый каркас, предметные функции ещё предстоит спроектировать и реализовать. Полные требования: [spec.md](spec.md).

- Модульный монолит на Python/FastAPI, отдельные API и worker.
- React + TypeScript + Vite; дизайн утверждается до реализации пользовательских экранов.
- PostgreSQL + pgvector, Redis + Celery, локальный Docker Compose.
- Поток: импорт → извлечение → фрагменты → обработка LLM → связывание сущностей → индексация → доступ с учётом прогресса.
- Базовая карта готовится для всей книги; дополнительная глубина может запрашиваться отдельно.
- Адаптер провайдера скрывает различия LLM API; модель, промпт и источники версионируются.
- Серверный контроль границы чтения действует до поиска и передачи контекста в модель. Смешанные данные скрываются или пересоздаются. Модель может знать сюжет по обучению.
- Исходные файлы и личные заметки хранятся отдельно; нужно определить схему резервного копирования и импорт/экспорт.

Текущий `GET /health` отражает состояние процесса, а не готовность зависимостей. Postgres и Redis запущены как инфраструктурные заготовки, интеграция отсутствует. Отдельная графовая БД пока не выбрана.
