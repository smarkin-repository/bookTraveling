# BookTravaling

Локальное пространство для исследования книг: карта событий, персонажей и связей с опорой на исходный текст.

**Состояние:** стартовый технический каркас. Импорт книг, анализ, поиск и пользовательский интерфейс ещё не реализованы. Работают только заготовки API и интерфейса, если зависимости установлены. Продуктовый макет предстоит утвердить до реализации интерфейса.

## Локальный запуск

Нужен Docker с Compose и доступ к интернету для первоначальной загрузки образов и зависимостей.

```bash
cp .env.example .env
docker compose up --build
```

Открыть UI: http://localhost:5173 . Состояние API: http://localhost:8000/health . Документация API: http://localhost:8000/docs .

В `.env` предусмотрен локальный пароль базы для разработки. Приложение пока не работает с книгами, БД или LLM: запущенные Postgres и Redis только подготовка окружения. Изменение пароля существующего тома Postgres требует отдельной настройки внутри БД.

```bash
docker compose down
```

Эта команда оставляет том базы. Не добавляй `--volumes`, если нужно сохранить данные.

## Локальные проверки

Python 3.12+ и Node.js 22.12+ (или 24) требуются для запуска вне контейнера.

```bash
python -m pip install -e './backend[dev]'
pytest backend/tests
cd frontend
npm ci
npm run build
```

Зависимости frontend зафиксированы в package-lock.json; для backend пока используются диапазоны без lock-файла. API-ключи, пользовательские книги и заметки не следует хранить в Git.
