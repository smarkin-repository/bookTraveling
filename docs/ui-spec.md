# UI — статус: не утверждён

Сначала создать и показать визуальную концепцию. После её обсуждения — локальный интерактивный прототип с демонстрационными данными; зафиксировать макет и согласовать его с пользователем до реализации продуктовых экранов.

Сценарии: библиотека; загрузка и прогресс обработки; книга и граница чтения; обзор главы; персонаж и источники; карта связей; личные заметки; исследовательский вопрос. Учесть пустые состояния, загрузку, ошибки и режим без спойлеров; версии для мобильного и desktop.

Существующая страница `frontend/src/main.tsx` — техническая заглушка, не утверждённый дизайн.
